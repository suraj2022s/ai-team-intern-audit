(a) KV-cache bytes per token
    = 2 (K,V) x layers(28) x kv_heads(8) x head_dim(128) x bytes/param(2)
    = 2 x 28 x 8 x 128 x 2
    = 114,688 bytes/token  (~112.0 KiB/token)

(b) Max concurrent 4096-token sequences
    total GPU memory budget   = 24 GB x 0.92 util = 22.080 GB
    - model weights           = 4.20e+09 params x 2 bytes = 8.400 GB
      (NOT called out separately in model_spec.md's overhead line, but weights
       obviously occupy GPU memory too -- omitting this would overstate capacity)
    - non-KV runtime overhead = 1.600 GB
    = usable KV-cache memory  = 12.080 GB
    max_seqs = usable_KV_mem / (bytes/token x 4096)
             = 12.080e9 / (114688 x 4096)
             = 25.72  -> ~25 concurrent full-length (4096-token) sequences
